Hashed Hierarchical Wheel Timer · 对应 esrrhs/wheel_timer（仿 Folly HHWheelTimer）

教学尺寸：本演示使用 WHEEL_BITS = 3 → 每层 8 个槽、共 4 层，tick = 1 单位，便于看清插入与轮转。 真实代码为 WHEEL_BITS = 8（每层 256 槽）、DEFAULT_TICK_INTERVAL = 10ms。 层级判定与级联逻辑与 wheel_timer.h 一致：按 diff = end_tick − expireTick_ 落入对应层，层 0 指针回绕时 CascadeTimers 将高层定时器重新 AddImpl。

操作日志

① 插入 Insert

delay → end_tick；按 diff 选层，slot = (end_tick ≫ bits×layer) & mask；写入 buckets_ 与 timer_map_。

② 触发 Trigger

Update 推进 expireTick_；弹出层 0 当前槽内全部定时器并返回 ID 列表。

③ 轮转 Cascade

层 0 指针 idx==0 时，从高层对应槽取出定时器并重新 AddImpl（降级到更低层）。

④ 删除 Delete

按 id 查 timer_map_，从所在 bucket 向量 swap-remove，再擦除 map 项。
