Operation log

① Insert

delay → end_tick; pick layer by diff; slot = (end_tick ≫ bits×layer) & mask; write buckets_ and timer_map_.

② Trigger

Update advances expireTick_; pop all timers in the current layer-0 slot and return their IDs.

③ Cascade

When layer-0 pointer idx==0, take timers from the matching higher-layer slot and re-AddImpl (demote to a lower layer).

④ Delete

Look up id in timer_map_, swap-remove from the bucket vector, then erase the map entry.
